FastGo Full Stack Java JEE Project

FastGo - Full Stack Food Delivery App

A feature-rich Zomato-style food ordering platform built using Java Servlets, JSP, JDBC, MySQL, HTML5, and Vanilla CSS3.

Java 17 / 25 JEE Servlets & JSP JDBC & MySQL 8.0 Paytm / PhonePe Gateway 10 Restaurants & 100+ Dishes

Project Architecture Note

FastGo is a Full-Stack Java Enterprise Web Application requiring a Java Servlet Container (Tomcat / Jetty) and a MySQL Database backend to run. GitHub Pages hosts static web pages.

Application Features

10+ Top Restaurants

Features 10 curated restaurants with Unsplash food imagery, ratings, price for two, delivery times, and cuisine filters.

100+ Mouthwatering Items

Each restaurant offers 10 specialized menu items complete with Veg/Non-Veg indicators, pricing, and descriptions.

Multi-Step Payment Gateway

Includes address review step followed by Paytm, PhonePe, Google Pay (GPay), Credit Card, and Cash on Delivery options.

Dynamic Shopping Cart

Real-time cart calculation with promo code discounts (FASTGO50), delivery fees, and taxes.

Admin Management Dashboard

Dedicated admin portal to view all customer orders, update order status, manage menu items, and view total sales revenue.

Live Order Tracking

Order success tracking page with item breakdown, payment status, estimated delivery time, and customer address.
